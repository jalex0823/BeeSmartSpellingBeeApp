## Why This Works

The original code was:
1. Show buttons
2. Return from `showFeedback()`
3. Continue executing
4. Call `loadNextWord()` anyway

**The problem:** `showFeedback()` returns immediately, it doesn't wait for user input!

**The solution:** Check if answer was incorrect, and if so, return BEFORE the `loadNextWord()` call. The retry handlers will call `loadNextWord()` after the user makes their choice.
