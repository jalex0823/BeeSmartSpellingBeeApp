## 🎯 Naming Convention

Each avatar includes three components:

1. **Display Name** (public-facing, shown to customers)
   - Format: `[Name] Avatar`
   - Example: "Knight Bee Avatar"

2. **Reference Name** (internal, shown only in App Store Connect)
   - Format: `BeeSmart – [Name]`
   - Example: "BeeSmart – Knight Bee"

3. **Product ID** (used in code, cannot be changed after creation)
   - Format: `com.beesmart.avatar.[slug]`
   - Example: `com.beesmart.avatar.knight-bee`
   - Note: Uses hyphens, not underscores

## ✅ Apple Requirements Compliance

### ✓ Display Names
- All individual avatars end with " Avatar"
- Clearly indicates what user receives (character unlock)
- Consistent across all 26 avatars
- Bundles/packs do NOT have "Avatar" suffix (correct)

### ✓ Reference Names
- Use "BeeSmart – [Name]" format
- Provides branding and context
- Visible only in App Store Connect

### ✓ Product IDs
- Use reverse-domain notation: `beesmart.avatar.[slug]`
- Use underscores for multi-word names
- Cannot be changed after creation
- Consistent, clean, future-proof

### ✓ IAP Types
- **Non-Consumable**: Individual avatars, bundles, packs
- **Auto-Renewable Subscription**: Hive Membership

### ✓ Pricing Tiers
- Free: 6 avatars (no IAP needed)
- Tier 1 ($0.99): 11 avatars
- Tier 2 ($1.99): 9 avatars
- Custom pricing for bundles and subscriptions

## 📝 App Store Connect Setup Checklist

For each avatar IAP:

- [ ] Product Type: **Non-Consumable**
- [ ] Product ID: Use exact ID from this document (cannot change later)
- [ ] Reference Name: `BeeSmart – [Avatar Name]`
- [ ] Display Name: `[Avatar Name] Avatar`
- [ ] Price Schedule: Select appropriate tier ($0.99 or $1.99)
- [ ] Description: Kid-friendly description from avatar_catalog.py
- [ ] Screenshot: 640×920px PNG (from avatar thumbnails)
- [ ] Review Information: Mark "Cleared for Sale"
- [ ] Submit with app binary for review
