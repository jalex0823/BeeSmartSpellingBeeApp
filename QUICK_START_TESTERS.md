# 🐝 BeeSmart Spelling Bee - Quick Start for Testers

## 3 Simple Steps to Start Testing:

### 1️⃣ Click Your Testing Link
You'll receive a link like: `https://play.google.com/apps/internaltest/...`

**Important:** Use the Gmail account that was added to the tester list!

### 2️⃣ Become a Tester
- Click **"Become a tester"** on the webpage
- Accept terms
- Wait a few seconds

### 3️⃣ Download & Test
- Click **"Download it on Google Play"**
- Install the app
- Start testing!

## 🎯 Quick Test Checklist (15 minutes):

✅ **Upload words** - Try uploading a text file with spelling words  
✅ **Take a quiz** - Complete at least one quiz using voice or keyboard  
✅ **Earn points** - Check if points appear in your dashboard  
✅ **Pick an avatar** - Try selecting different bee characters  
✅ **Create account** - Register and log back in
