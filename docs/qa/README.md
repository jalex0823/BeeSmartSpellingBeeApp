# QA Docs

This folder contains lightweight, repeatable QA artifacts for BeeSmart.

## What to run before release

- `../../SMOKE_TEST_CHECKLIST_QUIZ_PIPELINE.md`
  - End-to-end smoke checklist for the quiz pipeline.

## How to record results

Create a dated copy of `results_template.md` (or just duplicate it) and fill in PASS/FAIL.

Example naming:
- `results_2025-12-20_web.md`
- `results_2025-12-20_ios.md`
