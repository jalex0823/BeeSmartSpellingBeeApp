## The Fix ✅

Three strategic changes to control WHEN information displays:

### 1️⃣ First Wrong = Buttons ONLY
- Show: Choice buttons + 10-sec timer
- Hide: Everything else (message, phonetic, spelling, hints)

### 2️⃣ User Chooses = Full Info
- Show: Message + spelling + phonetic + Next Word button
- Trigger: When user clicks Retry or Answer

### 3️⃣ Second Wrong = Always Show
- Show: Everything (message + spelling + phonetic)
- Trigger: Automatically after second attempt
