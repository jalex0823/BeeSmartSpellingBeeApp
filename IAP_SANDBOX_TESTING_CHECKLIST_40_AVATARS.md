2. **JavaScript Purchase Function**:
   ```javascript
   async function purchaseAvatar(avatarId, productId, price) {
       try {
           // Check if IAP available
           if (!(window.BeeSmartIAP && typeof window.BeeSmartIAP.purchase === 'function')) {
               showErrorDialog('Purchase Not Available', 'Please use the iOS app to purchase avatars.');
               return;
           }
           
           // Show loading
           showLoadingDialog(`Purchasing ${avatarId.replace('-', ' ')}...`);
           
           // Call native IAP
           const result = await window.BeeSmartIAP.purchase(productId);
           
           // Handle cancelled
           if (result.cancelled) {
               hideLoadingDialog();
               showDialog('Purchase Cancelled', 'You can purchase this avatar anytime!');
               return;
           }
           
           // Handle pending
           if (result.pending) {
               hideLoadingDialog();
               showDialog('Purchase Pending', 'Your purchase is being processed. Please check back later.');
               return;
           }
           
           // Verify with backend
           const verifyResp = await fetch('/api/iap/verify/apple', {
               method: 'POST',
               headers: {'Content-Type': 'application/json'},
               body: JSON.stringify({
                   product_id: productId,
                   transaction_id: result.transactionId || result.transaction_id,
                   payload: result.payload
               })
           });
           
           const data = await verifyResp.json();
           
           hideLoadingDialog();
           
           if (data.success) {
               showSuccessDialog(
                   'Avatar Unlocked! 🎉', 
                   `${avatarId.replace('-', ' ')} is now yours!`
               );
               
               // Refresh avatar list
               setTimeout(() => {
                   location.reload();
               }, 1500);
           } else {
               showErrorDialog('Purchase Failed', data.error || 'Unknown error occurred.');
           }
           
       } catch (error) {
           hideLoadingDialog();
           console.error('Purchase error:', error);
           showErrorDialog('Error', error.message || 'Purchase failed. Please try again.');
       }
   }
   ```

3. **UI States**:
   - Free avatars: No button
   - Locked (earned): Show unlock points required
   - Locked (purchasable): Show price + purchase button
   - Owned: Show checkmark or "Selected" state

## 📞 TROUBLESHOOTING

### Problem: "Product Not Found" Error

**Cause**: Product ID mismatch between code and App Store Connect

**Solution**:
1. Check exact Product ID in App Store Connect
2. Update code to match exactly (case-sensitive!)
3. Rebuild and reinstall app

### Problem: Purchase Sheet Shows Wrong Price

**Cause**: App Store Connect price tier incorrect

**Solution**:
1. Update price tier in App Store Connect
2. Wait 1-2 hours for changes to propagate
3. Re-test

### Problem: "Cannot Connect to iTunes Store"

**Cause**: Sandbox account not configured correctly

**Solution**:
1. Settings → App Store → Sign out completely
2. Open app, attempt purchase
3. Sign in with sandbox account when prompted
4. Never sign into sandbox in Settings → Apple ID (only in Settings → App Store → Sandbox)

### Problem: Purchase Succeeds but Avatar Doesn't Unlock

**Cause**: Backend entitlement logic not working

**Solution**:
1. Check backend logs for `/api/iap/verify` call
2. Verify product ID parsing logic
3. Check `_apply_entitlement()` function
