# Store Assets Checklist — BeeSmart Spelling Bee

## Universal Branding
- Keep bee theme; high contrast; kid‑friendly typography
- Avoid small text; keep captions large and readable

## Apple (App Store)
- Icon: 1024×1024 PNG (no alpha); safe area respected
- Screenshots (PNG/JPG):
  - iPhone 6.7″: 1290×2796
  - iPhone 6.5″: 1242×2688
  - iPad 12.9″: 2048×2732
  - iPad 11″: 1668×2388
- App preview (optional): ≤30s .mp4/.mov

## Google Play
- Play icon: 512×512 PNG (no alpha recommended)
- Feature graphic: 1024×500 JPG/PNG
- Screenshots (PNG/JPG):
  - Phone: ≥3 (e.g., 1080×1920)
  - 7″ tablet: ≥1 (e.g., 1200×1920)
  - 10″ tablet: ≥1 (e.g., 1600×2560)
- Promo video: YouTube URL (optional)

## Suggested Screenshot Storyboard
1. Home/Menu with Upload/OCR/Quiz
2. Upload file (CSV/TXT/DOCX/PDF)
3. OCR import screen (photo of worksheet)
4. Quiz question with kid‑friendly definition
5. Voice answer prompt (mic) and keyboard option
6. Hint shown (no answer reveal)
7. Progress/streaks screen
8. Settings/About with privacy links

## File Naming Tips
- app-ios-01-home.png, app-ios-02-upload.png, …
- app-android-01-home.png, …

## Delivery Checklist
- Confirm device frames and language locale
- Verify text legibility at 50% zoom
- Compress images without visible artifacts
