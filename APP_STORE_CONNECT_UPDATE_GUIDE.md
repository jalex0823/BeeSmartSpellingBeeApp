## ⚠️ IMPORTANT: Product IDs Cannot Change!

Your Product IDs are **CORRECT** and **CANNOT BE MODIFIED**:

## ✏️ What You Need to Update: Display Name ONLY

### In App Store Connect:
1. Click on each In-App Purchase product
2. Go to **App Store Localization** section
3. Update **Display Name** field to include "Avatar"
4. Save changes

## 🔑 Key Points

✅ **Do Update**: Display Name (add " Avatar" suffix)  
✅ **Do Update**: Reference Name (should match Display Name)  
❌ **Don't Touch**: Product ID (locked after creation)  
❌ **Don't Touch**: SKU  
❌ **Don't Touch**: Price Tier  

## 💡 Why This Matters

Apple requires that In-App Purchase names clearly reflect what the user receives. Adding "Avatar" makes it crystal clear this is a character unlock, not consumable content or subscription.

## 🚫 Common Mistakes to Avoid

1. ❌ Don't try to change Product ID
2. ❌ Don't remove "Avatar" from the name
3. ❌ Don't use inconsistent naming (some with Avatar, some without)
4. ✅ DO keep all names ending with " Avatar"

## ✅ Verification

After updating, check that:
- [ ] Every avatar product Display Name ends with " Avatar"
- [ ] Product IDs are unchanged
- [ ] Reference Names match Display Names
- [ ] All products still marked "Cleared for Sale"
